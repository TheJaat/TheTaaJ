httpd

httpd is a small web server written for TheTaaJ in Rust. It answers GET and HEAD, one connection at a time, one request per connection, and gives out the files under one directory of the disk.

/ or a directoryits index.html
a file under the site200, the file
nothing by that name404

POST, PUT, DELETE405
no request in 10 seconds408

What it may touch

The shell gives httpd two services and nothing else: the network, and the channel to the file service that can only read. A request cannot change a byte on the disk, because the program that answers it has no way to.
