This page came from TheTaaJ

The bytes you are reading were sent by httpd, a program running on TheTaaJ itself: read from its own file system, handed to its own TCP, wrapped in its own IPv4 and Ethernet frames, and put on the wire by its own driver for the network card.

Here is the way they came:

  httpd (HTTP) ── files.look ──▶ file service ──▶ TaajFS ──▶ virtio disk
    │
    └── net ──▶ network service: TCP ▸ IPv4 ▸ ARP ▸ Ethernet
                      │
                      └── nic ──▶ virtio-net driver ──▶ the wire ──▶ you

What is in it

  • A 64-bit microkernel for x86-64 and AArch64, booted by BIOS or UEFI.
  • Processes, threads and several CPUs; channels and handles between programs.
  • Drivers outside the kernel: keyboard, disk, network card.
  • A file system of its own (TaajFS), a shell, and a C library.
  • A network stack: ARP, IPv4, ICMP, UDP, TCP - and now HTTP.

The journal

Every step is written down as it is made - why it was needed, how it works, what went wrong, and how it was tested. The journal is published at www.thejat.in.
